# IC 設計的 EDA 是什麼？

**EDA（Electronic Design Automation，電子設計自動化）**是半導體產業的基石。如果說台積電是製造晶片的「工廠」，那 EDA 就是工程師用來畫出晶片藍圖的「超級軟體」，專門用來設計、模擬和驗證積體電路（IC）與印刷電路板（PCB）的軟體工具集合。

簡單來說，如果把設計晶片比喻成蓋一棟有數百億個房間的摩天大樓，**EDA 就是建築師手上的 AutoCAD 與結構運算軟體**。因為現代晶片內含動輒數十億個電晶體，工程師不可能再像早期一樣用手工繪製電路圖，必須完全仰賴 EDA 工具來自動完成佈局、走線與驗證。

## 一、摘要
電子設計自動化（Electronic Design Automation, 簡稱 EDA）是現代半導體產業的基石，涵蓋了用於設計、模擬、驗證與製造積體電路（IC）的各類軟體工具與演算法。隨著製程技術推進至奈米甚至埃米級，單一晶片內部常包含數百億個電晶體。面對如此龐大的複雜度，傳統的手工電路繪製已無法實現，必須完全仰賴 EDA 工具來進行自動化運算、佈局與物理驗證。

## 二、	EDA 在 IC 設計流程中的關鍵角色 
EDA 工具貫穿了整個 IC 設計的生命週期，主要可分為以下幾個核心階段：

* **前端設計與邏輯合成（Frontend & Synthesis）：** 
  工程師會使用硬體描述語言（HDL，例如 Verilog 或 VHDL）來定義晶片的邏輯功能。EDA 工具能將這些抽象的程式碼「合成」成由邏輯閘（Logic Gates）組成的真實電路網表（Netlist）。這就像是在硬體模擬器中撰寫 `.hdl` 檔建構 ALU 或 CPU 後，靠軟體將其轉換為實際的邏輯架構。
* **後端實體設計（Backend Physical Design）：** 
  包含佈局與走線（Placement & Routing, P&R）。EDA 軟體會決定這幾十億個邏輯閘在矽晶片上的實際擺放位置，並自動規劃連接它們的超微細金屬導線，同時考量散熱、面積與傳輸延遲。
* **驗證與模擬（Verification & Simulation）：** 
  在真的把設計圖交給台積電（TSMC）等晶圓廠製造之前，必須確保設計 100% 正確（因為光罩開模成本極高）。EDA 工具會進行各種極限模擬，檢查是否有時序違規（Timing violation）、漏電，以及進行設計規則檢查（DRC）與電路佈局驗證（LVS）。

## 三、全球 EDA 產業的三大巨頭

目前的 EDA 市場是一個高度寡占的產業，全球超過 70% 的市佔率掌握在三大公司手中，沒有它們的軟體，全球的晶片設計公司（如聯發科、高通、NVIDIA、Apple）都無法開發新晶片：

1. **Synopsys（新思科技）：** 總部位於美國，全球市佔率第一，在邏輯合成與靜態時序分析工具上具有統治地位。
2. **Cadence（益華電腦）：** 總部位於美國，在類比（Analog）與混合訊號電路設計、以及後端佈局走線工具上非常強大。
3. **Siemens EDA（西門子，前身為 Mentor Graphics）：** 德國西門子收購，在電路板設計與後端實體驗證（如 Calibre 軟體）上是業界標準。

## 四、現代 EDA 輕量化實測：veryl2chip Web IDE
**veryl2chip Web IDE** 便是這類輕量化 EDA 發展的代表之一。這類工具打破了傳統 EDA 軟體動輒需要安裝數十 GB、綁定特定作業系統（如 Linux 伺服器）的痛點。其主要特色包含：

* **免安裝與雲端編譯：** 開發者可以直接在瀏覽器上撰寫硬體描述代碼，並在雲端或本地端利用 WebAssembly 即時進行語法檢查、編譯與模擬。
* **現代化語法與工具鏈支援：** 結合 Veryl 這類現代化語言，提供比傳統 Verilog/SystemVerilog 更安全的型別檢查與簡潔語法，並內建代碼自動格式化（Formatter）與代碼檢查工具（Linter）等現代軟體工程體驗。
* **從代碼到晶片的敏捷橋樑：** 「veryl2chip」的理念展現了從現代 HDL 代碼無縫轉換、合成至底層設計的潛力。對於快速原型開發、學術教學，或是推動開源硬體（Open-Source Hardware）專案來說，是非常高效率的輕量化實測平台。

> **總結來說**，EDA 就是把人類的邏輯思維轉化為奈米級實體晶片藍圖的必備軟體平台；而像 veryl2chip Web IDE 這類的輕量化開源工具，正為未來的敏捷硬體設計開創全新的可能性。
