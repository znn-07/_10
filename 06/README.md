## 專案簡介

Hack 電腦是一座基於 16-bit 馮紐曼架構的機器。本組譯器負責將高階組合語言中的指令與符號，精準轉換為由 $0$ 與 $1$ 組成的 16 位元機器指令串，並處理：

* 空白字元與單行註解 (`//`) 的濾除
* 預定義符號與自訂變數的記憶體位址分配
* 標籤 (`(LABEL)`) 的跳轉目標解析

## Hack 機器語言規格

### A-指令 (A-Instruction)

A-指令用於將數值或記憶體位址載入到 $A$ 暫存器中。

* **語法格式：** `@value` 或 `@symbol`
* **二進位結構 (16-bit)：** `0vvvvvvvvvvvvvvv`
  * 最高位元為 `0` 表示此為 A-指令。
  * 後續 15 個位元代表非負整數數值 ($0 \le v \le 32767$)。

### C-指令 (C-Instruction)

C-指令用於執行 ALU 運算、指定運算結果寫入的暫存器或記憶體，以及進行條件跳轉。

* **語法格式：** `dest = comp ; jump`（`dest` 與 `jump` 欄位可選）
* **二進位結構 (16-bit)：** `111a cccc ccdd djjj`

| 位元區段 | 描述 |
| ----- | ----- |
| `111` | C-指令標頭前綴 |
| `a` | 指定 ALU 運算對象為 $A$ 暫存器 ($a=0$) 還是 $M$ (RAM[$A$]) 暫存器 ($a=1$) |
| `c1..c6` | ALU 控制位元（決定 $D+1$, $D-A$, $D\&A$ 等運算） |
| `d1..d3` | 運算結果寫入目的地 (`A`, `D`, `M`) |
| `j1..j3` | 條件跳轉條件 (`JGT`, `JEQ`, `JGE`, `JLT`, `JNE`, `JLE`, `JMP`) |

### 符號系統 (Symbols)

1. **預定義符號 (Predefined Symbols)：**
   * 虛擬暫存器：`R0` ~ `R15` 對應 RAM[$0$] ~ RAM[$15$]
   * 指標：`SP` ($0$), `LCL` ($1$), `ARG` ($2$), `THIS` ($3$), `THAT` ($4$)
   * I/O 記憶體映射：`SCREEN` ($16384$), `KBD` ($24576$)

2. **標籤符號 (Label Symbols)：**
   * 格式：`(LABEL_NAME)`
   * 指向下一行指令在 ROM 中的位址，用於 `JMP` 跳轉目標。

3. **變數符號 (Variable Symbols)：**
   * 任何非預定義且非標籤的 `@symbol` 均視為變數。
   * 從 RAM 位址 $16$ 開始依序自動分配記憶體。

## 組譯器架構設計

組譯器通常包含以下三大核心模組：

### 1. Parser (解析器)

* 負責讀取輸入檔 `.asm`。
* 自動剔除所有空白格、Tab 與註解 (`//`)。
* 將每行指令拆解為：指令類型 (`A_COMMAND`, `C_COMMAND`, `L_COMMAND`)、符號名稱 (`symbol`)、運算欄位 (`comp`)、目標欄位 (`dest`)、跳轉欄位 (`jump`)。

### 2. Code (二進位對照表)

* 將 `comp` 助記符轉換成 7 位元二進位字串 (`a` + $6$ 位元控制信號)。
* 將 `dest` 助記符轉換成 3 位元二進位字串。
* 將 `jump` 助記符轉換成 3 位元二進位字串。

### 3. SymbolTable (符號表)

* 維護符號名稱與記憶體位址的 Hash Table / Dictionary 映射。
* 初始化時載入所有預定義符號。

## 兩階段處理流程 (Two-Pass Assembly)

為了支援「前向引用（Forward Reference）」標籤跳轉，組譯採用 **Two-Pass** 機制：

```
+-------------------------------------------------------+
|                   1. 讀取 .asm 檔案                   |
+-------------------------------------------------------+
                           |
                           v
+-------------------------------------------------------+
|  First Pass (第一階段)                                 |
|  - 掃描全文並計算 ROM 行數                             |
|  - 紀錄標籤 (LABEL) 與對應 ROM 位址至 Symbol Table    |
|  - 忽略標籤列，不佔用 ROM 行數                         |
+-------------------------------------------------------+
                           |
                           v
+-------------------------------------------------------+
|  Second Pass (第二階段)                                |
|  - 再次掃描全文                                       |
|  - 翻譯 A-指令: 將數值或符號轉換為 15-bit 二進位      |
|    (若為新變數，由 RAM[16] 開始分配位址)               |
|  - 翻譯 C-指令: 查表拼接 16-bit 二進位碼              |
|  - 將每行 16 位元字串寫入 .hack 檔案                   |
+-------------------------------------------------------+
```

## 使用方法

### 執行環境

* **Python 3.x** / **Java 11+** / **C++17** （視具體實作語言而定）

### 指令範例

使用 Python 實作版本執行：

```bash
python assembler.py Prog.asm
```

執行後會在相同目錄下生成 `Prog.hack` 檔案。

可將產生的 `.hack` 檔案載入 Nand2Tetris 官方提供的 **CPU Emulator** 或 **Hardware Simulator** 進行模擬與測試。
